# problab-calculator
Calculate and graph probabilities or quantiles based on the most commonly used distributions in statistics
ProbLab — Calculadora de probabilidades
Aplicación web estática, en español, para calcular probabilidades y cuantiles de siete distribuciones: Binomial, Hipergeométrica, Poisson, Normal, t de Student, Chi-cuadrado y F de Snedecor.
Funcionalidades
Probabilidades acumuladas, de cola, exactas y entre dos valores.
Cálculo inverso: valor asociado a una probabilidad acumulada izquierda o derecha.
Gráfico de la distribución y resaltado del evento seleccionado.
Validaciones básicas y diseño adaptable a móviles.
